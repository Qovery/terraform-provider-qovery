# qovery_argocd_destination_cluster_mapping (Resource)

Manages a Qovery ArgoCD destination cluster mapping: it maps the URL of an ArgoCD destination cluster to a Qovery cluster.


## Example

```terraform
# https://kubernetes.default.svc is the in-cluster destination of the ArgoCD instance:
# the cluster ArgoCD runs on, here mapped to that same Qovery cluster.
resource "qovery_argocd_destination_cluster_mapping" "my_argocd_destination_cluster_mapping" {
  organization_id    = qovery_organization.my_organization.id
  agent_cluster_id   = qovery_cluster.my_cluster.id
  argocd_cluster_url = "https://kubernetes.default.svc"
  cluster_id         = qovery_cluster.my_cluster.id
}
```

## Schema

### Required

- `agent_cluster_id` (String) ID of the Qovery cluster that runs the ArgoCD instance. Changing it recreates the mapping.
- `argocd_cluster_url` (String) URL of the ArgoCD destination cluster, for example `https://kubernetes.default.svc`. Changing it recreates the mapping.
- `cluster_id` (String) ID of the Qovery cluster mapped to the ArgoCD destination.
- `organization_id` (String) ID of the organization. Changing it recreates the mapping.

### Read-Only

- `id` (String) ID of the mapping, in the import format `<organization_id>,<agent_cluster_id>,<argocd_cluster_url>`.
